# Shopping Cart MCP Server

A demo MCP (Model Context Protocol) server that lets authenticated users shop through LLMs such as ChatGPT, Claude and Gemini. It exposes the shopping-cart microservices from [spring-boot-kafka-example](https://github.com/mallikarjungunda/spring-boot-kafka-example) as MCP tools.

**Technical specification:** https://mallikarjungunda.github.io/shopping-cart-mcp-server/

The source of the spec page is [`docs/index.html`](docs/index.html).

## Status

Specification phase. See the delivery checklist in the spec for the phased plan.
